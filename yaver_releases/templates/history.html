Publish a release

Upload one zip for Windows and every Ubuntu version. The files inside are named with the version, for example yaver-windows-x64-0.9.79.zip and yaver-linux-x64-ubuntu-22.04-0.9.79.zip. This form does not ask for a version. Colleagues still download each system on its own. A zip that contains only one folder is opened before those names are read. Dependency zips are separate: one tool, with a VERSION file that is that tool's version. update.bat and update.sh do not install those.
