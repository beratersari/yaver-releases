How to use Yaver

Use this

Use the dashboard.

The Yaver dashboard is the page at http://<ip>:8080. Open Using it from the dashboard and follow the sections inside. That is the easier way. A question on a merge request or a pull request stays a comment, @name /ask. That command is not a button on the dashboard. Using it from external sites is for the Jira, GitLab, or Azure website. Using it on those websites is harder.
