Before anything else

Set AI_API_KEY and the network certificate.

OpenCode and Codex read AI_API_KEY. Yaver passes that same variable to Claude. Node reads NODE_EXTRA_CA_CERTS to trust the network certificate. Set both system variables on the whole machine before those tools. The certificate address is the external link in the description below. Close every terminal and open a new one, then start Yaver again. On Linux, sign out and sign in so the system environment loads.

API key

Replace YOUR_TOKEN with the key. OpenCode and Codex read this system variable. Yaver passes it to Claude. Do not paste the key into their config files.

Windows. Run PowerShell as administrator. This command sets the system variable.

[Environment]::SetEnvironmentVariable("AI_API_KEY", "YOUR_TOKEN", "Machine")

Linux. This command sets the system variable in /etc/environment.

sudo sed -i '/^AI_API_KEY=/d' /etc/environment && echo 'AI_API_KEY=YOUR_TOKEN' | sudo tee -a /etc/environment >/dev/null

Windows

Download it and put it in C:\certs\network-ca.crt. Run PowerShell as administrator. This command sets the system variable.

[Environment]::SetEnvironmentVariable("NODE_EXTRA_CA_CERTS", "C:\certs\network-ca.crt", "Machine")

Linux

Download it and put it in ~/certs/network-ca.crt. This command adds the system variable to /etc/environment.

grep -q '^NODE_EXTRA_CA_CERTS=' /etc/environment || echo "NODE_EXTRA_CA_CERTS=$HOME/certs/network-ca.crt" | sudo tee -a /etc/environment >/dev/null
